# 💼 Portfólio · Nicole Chagas

Meu portfólio profissional como estudante de Engenharia de Software em transição para **DevOps e Cloud**. Reúne meus laboratórios de Linux, Docker e Kubernetes, o site que fiz para a Rústicos Diniz, meus certificados e um formulário para propostas.

🌐 **Site:** [SEU-ENDERECO.cloudfront.net](https://SEU-ENDERECO.cloudfront.net)

## ✨ O que tem no site

- **Pipeline de carreira:** painel animado que mostra em que etapa estão meus estudos (Linux, Docker, Kubernetes e Cloud)
- **Sobre mim** e áreas de interesse
- **Certificados** em ordem cronológica
- **Projetos** com links para os repositórios
- **Formulário de proposta** para empresas e recrutadores
- Layout responsivo, navegação por teclado e respeito a `prefers-reduced-motion`

## 🛠️ Tecnologias

| Área | Ferramentas |
|------|-------------|
| Site | HTML5, CSS3, JavaScript (um único arquivo, sem frameworks) |
| Formulário | [Formspree](https://formspree.io) |
| Hospedagem | AWS S3 (bucket privado) + Amazon CloudFront (HTTPS) |
| Acesso ao bucket | Origin Access Control (OAC) |
| Fontes | Chakra Petch, IBM Plex Sans e IBM Plex Mono (Google Fonts) |
